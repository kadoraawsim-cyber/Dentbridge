# Archived Student Pilot Form

This folder preserves the inactive DentBridge student pilot application form
that was previously served at `/student-pilot`.

The form was used for an earlier student pilot and collected about 30
submissions. It is no longer active and must not be publicly served from the
live DentBridge site.

Archived files:

- `dentbridge-form.html` - original static form
- `dentbridge-logo.png` - original form asset
- `logo.png` - original form asset

The archived HTML contains the historical Google Apps Script submission
endpoint used by the old pilot form. Keep this folder outside `public` unless a
future task explicitly migrates or reactivates the workflow through a safe,
controlled implementation.
